# Life RPG Demo Testing

## Test Goal

首轮 demo 的目标不是验证所有 RPG 系统，而是验证测试者是否能完成一次清晰、温和、有反馈的每日循环：

1. 注册或登录。
2. 创建角色档案。
3. 进入每日指挥中心。
4. 完成晨间加载并选择今日主线。
5. 创建一个任务，或记录一个已完成任务。
6. 领取奖励。
7. 夜间封存。
8. 在人生日志里回看今天。

## Recommended Tester Script

请测试者按这个顺序操作，并记录卡住的位置：

1. 用自己的邮箱注册，或使用组织者私下提供的测试账号登录。
2. 完成开局创建角色，不需要填写真实敏感信息。
3. 在首页确认系统给出的下一步行动是否明确。
4. 进入晨间仪式，选择一个今日主线。
5. 在任务页创建一个 5-15 分钟能完成的小任务。
6. 完成任务，观察奖励解释是否看得懂。
7. 进入夜间封存，即使今天只有 0-1 个任务也尝试封存一句话。
8. 打开人生日志，确认今天的记录能找到。
9. 刷新页面，再确认首页、任务和日志是否仍能正常显示。

## Smoke Checklist

- 新用户可以注册、登录并完成 onboarding。
- 返回用户登录后不会因为清缓存而无意义重复 onboarding；系统会尝试从 `profiles` 恢复核心角色档案。
- 登录页生产环境不显示内部测试账号和 debug 状态。
- 晨间加载能写入今日主线，并能跳到任务页。
- 任务创建失败、登录失效、保存失败时有可见错误提示。
- 完成任务后 XP、晶石、任务完成状态和最近完成记录更新。
- 夜间封存支持 0 任务休整日，并显示封存进度或错误提示。
- 人生日志能看到本地日志和云端封存摘要。
- `/feedback` 页面可打开；如果配置了 `NEXT_PUBLIC_FEEDBACK_URL`，能跳到外部反馈表。
- `npm run lint` 和 `npm run build` 通过。

## Known Limits For Testers

- 首轮 demo 以中文 Web 体验为主。
- 任务、XP、晶石、奖励流水和封存日志会写入 Supabase；部分角色细节、技能树、外观、长期任务和临时 UI 状态仍保留在本机。
- 换浏览器或清缓存时，系统会尝试恢复核心角色档案，但个别本地装饰或实验玩法状态可能重置。
- 商店、背包、周常、史诗任务、收藏和独立文字冒险是后置玩法，不是本轮测试重点。
- 如果 Supabase 开启邮箱确认，测试者需要先完成邮箱确认再登录。

## Feedback Template

请测试者反馈时尽量包含：

- 测试账号邮箱或大概测试时间。
- 使用设备和浏览器。
- 卡住的步骤。
- 点击了什么。
- 页面显示的错误、空白、加载中状态或截图。
- 刷新后是否仍能复现。
